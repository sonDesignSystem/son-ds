# Contributing to Son Design System

Thanks for contributing ❤️

## Getting Started

1. Fork the repo
2. Clone your fork

```bash
git clone https://github.com/sonDesignSystem/son-ds.git
cd son-ds
```

3. Install dependencies

```bash
npm install
```

4. Build the package

```bash
npm run build
```

---

## Testing Changes

Since this is a package, test it by linking:

```bash
npm link
```

Then in your test project:

```bash
npm link son-ds
```

---

## Guidelines

* Keep components reusable and minimal
* Follow existing structure
* No breaking changes without discussion

---

## Commits

```
feat: add Button

```

## Pull Requests

* Clear description
* Focused changes
* No unrelated edits

---

## Code Style

* TypeScript only
* No unused code
* Match existing patterns
